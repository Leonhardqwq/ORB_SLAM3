## 实现及模型对应

外部依赖仍为 `B(k-1) → T(k) → B(k)`。T 使用原有左右图像特征提取，两个内部线程 join 后才返回；B 顺序完成 LocalMapping、回环检测/校正和原算法触发的 GBA。同步 GBA 直接在 B 的调用线程运行，全部地图更新及耗时在 B 返回之前完成。没有让后台 GBA 越过边界，没有删关键帧、跳过优化或以事后轨迹替代 T 返回时的在线位姿。

固定模式显式设置 `Execution.serialStereo: 0` 才启用内部并行；缺省仍保留旧固定串行行为。同步回环需同时显式设置 `Execution.synchronousLoop: 1` 与 `loopClosing: 1`，未声明同步归属的固定回环仍拒绝。原生入口继续使用原来的特征并行、回环线程与后台 GBA；新 CMake 依赖复用选项默认关闭。研究范围仍是 pinhole 非惯性双目、无 Viewer/Atlas 文件，不扩大成所有传感器和场景已验证。

`LocalMapping::StopForLoopCorrection` 只在同步 mapper 本轮处理结束、队列为空时直接确认停止；原生模式仍仅发停止请求。B 返回前检查无遗留 GBA、回环队列排空、mapper 已释放。重置清理同步回环候选引用，关闭仍由固定 API 状态机约束。

每帧增加 T 前、T 后、B 后线程观测与回环/校正/合图/GBA 累计计数。显式 `joined_stereo` 审计允许 T 内部峰值最多 3 个线程，所有外部边界必须回到 1 个线程；旧审计默认仍要求全程单线程。源码 join、同步调用和边界观测共同支持本次判断，不能声称已经形式化证明所有线程不存在竞态。

有效耗时仍是就绪后间隙加模块墙钟耗时；回环与 GBA 进入 B 的耗时，不改变原图。边界时间与原 `g/Phi` 的整数纳秒记账逐帧一致，不代表模式外生性、给定模式后的时间独立性和联合分布假设成立。没有拟合 F/Q 或进行实际反向 DP 概率预测。

## 先发现并修复的真实错误

首版两次无回环长回放完成，首次真实回环后则报 `Mapper still stopped after synchronous backend`。原因是 `mbFinished` 初始为 true，原生 `Run()` 会把它改为 false，而同步入口没有这个转换，导致 `Release()` 提前返回。当前在同步 `ProcessRound()` 开始时明确进入运行状态，并拒绝已请求结束的后续工作。

旧错误版本、退出状态、已处理帧数和日志保留在 JSON 的 `historical_failed_batch`，未写成实用性失败或成功。C++ 回归覆盖重复停止/释放、下一轮、结束请求以及原生异步停止；**新库通过，同一测试加载旧错误库时按预期失败**。修复后重新开始全部四配置对照，没有将旧版时间混入新版比较。

V1_02_medium 从序列开头连续运行，四配置各 3 个新进程、顺序交错、全部串行计时。每次 1600 个评估帧；ATE/真值覆盖预定 k=20..1599，全部帧仍进入有效位姿、重置、时延、资源和记账指标。h=τ=50 ms，H=20；没有按结果修改阈值、丢弃超时帧或重新选择种子。这是复用同一序列的探索性配置诊断，不是独立场景或最终留出验证。

原生程序没有本轮同步 B 边界，原始事件文件中其 B 时间只是回放器的空操作时间，不能当成原生后台建图耗时。RSS 包含预加载图像；CPU 是评估期间全部进程线程的 CPU 时间与墙钟时间之比。

同步回环三次的按时帧比例为 98.5000–99.0625%，最长 B 为 204.1–249.7 ms。`loop_backlog_diagnostic` 保存了修正帧及紧随其后的积压段；这是实测时间邻接及队列传播记录，不能把全部 B 耗时唯一归因于 GBA，后续仍需细分计时。H=20 的窗口成功比例保留在单次审计证据中，仅为相关轨迹上的描述。

固定串行在新版本中的 ATE 重复结果与旧版 0.266 m 不同；并行与原生本身也有重复间差异。不能将所有差值归因于某一开关、把一次最好轨迹作为一般优势，或把旧版和新版结果合成稳定性估计。新旧主要编译优化参数一致；首次轨迹分歧、线程调度、内存/遍历顺序及数值路径的作用仍待定位。

```bash
python3 tools/run_contained_backend_comparison.py   --source /path/to/isolated/source   --data /path/to/V1_02_medium   --output /path/to/new-comparison   --reference /path/to/reliability-study/experiments/periodic-feedback/src/evaluate.py   --protocol docs/contained-backend-protocol-v2-2026-10-18.json
```
