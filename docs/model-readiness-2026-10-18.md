## 当前执行对象

指定固定调度下的 ORB-SLAM3，非惯性针孔双目。T 内部双目并行结束后返回；B 包含本轮局部建图、回环及触发的完整 GBA，返回后下一 T 才开始。保持原生默认入口。数据为预加载 EuRoC 周期回放，不声称道路或实时相机部署验证。

令 x 为上一 B 相对本轮释放的剩余完成时间，则 D=x+S_T，下一历史 x'=[x+S_T+S_B-h]_+。当前测量使用另行获准的有效耗时（就绪后间隙加执行时间）；前驱等待仍在 x 内，不重复计入 S。精简报告及 Lean 定理未改写；逐路径记账不是概率预测。

## 两类验收分开

| 类别 | 决定什么 | 当前规则 |
|---|---|---|
| 结构和测量 | 能否构造可信联合样本 | 固定依赖、调用/帧对齐、边界结束、非负且不重复计时、源码与二进制对应、插桩复测；错误须修复 |
| 数据与概率 | 能否使用原 F/Q 进行预测 | 独立运行、完整尾部、运行级划分、原三项概率条件分别检查；证据不足不能记通过 |
| 应用性能 | 此配置是否达到预定部署目标 | 原 99% 按时率、ATE、资源及相对原生门槛继续报告；未达标不阻止前两类研究 |

旧 E3 包含两类问题，今后分别记录 E3-data 与 E3-practical。前者达到本次诊断所需条件即可进入 E4 适用性诊断；后者保留未通过状态。E4 诊断已开始不等于 E4 验收通过，更不等于 E5/E6 已验证。崩溃、未知取消/丢帧、未定义重置语义仍是模型输入问题，不能当成长耗时自动吸收。无效定位与纯时延事件分列，不能删掉失败帧或改变 R_H 定义。

## 本次顺序和验收

1. 核对新旧源码、二进制、库和 Git 保护状态。复用 v3 构建，无算法改动。
2. 固定同步回环配置，V102 从起点运行，3 次插桩、3 次无插桩，按事前顺序串行执行，每次 1600 个评估帧。原含等待墙钟中位数比值上限 1.05 保留；同时报告 CPU 比值及定位变化，不把该比值解释为每次测量的扰动上界。
3. 测量门槛通过后，同版本 V101 完成 3 次 1600 帧采集；逐条校验边界、记账及联合样本。所有性能失败保留。不混合同一序列的不同配置或两个序列为一个 F。
4. 先检验 M=1 的联合经验分布候选及历史依赖；原同轮 T/B 对齐，不分别独立抽样。旧 V102 第 1/2 运行作为候选构造，第 3 运行和本次新运行分别标注探索检查与新诊断检查。新 E2 数据不是最终留出测试集。
5. 上一轮关键帧指示仅作模式候选诊断；本轮回环结果不作先验模式。历史变量的预测力用于反驳过简候选，不能把它们塞进模式后自动声称原 Q 条件成立。细节见冻结的 JSON 协议。
6. 保存数据完整性、尾部事件数量、积压传播与概率条件结论。若原条件不获支持，保留诊断并明确下一项可实施工作，不进行认证式 E5/E6 预测。

本次只检验有限范围的候选。三次运行不足以证明条件独立；不以不显著作为等价证据，不给相关帧/窗口套独立二项区间。

## 实际完成结果（2026-10-19）

E2 和诊断范围内的 E3-data 已通过，已实际推进至 E4 首轮诊断。E4 候选条件尚未获支持，E5/E6 未进入；这与积压或未达 99% 按时率是不同问题。

| 检查 | 实际结果 |
|---|---|
| 新采集 | V102 插桩/无插桩各 3 次，V101 插桩 3 次；9 次均完成，每次 1600 评估帧，共 14,400 帧；无无效定位帧 |
| 边界与计时 | 新 6 次插桩运行通过原审计，整数纳秒递推偏差 0；有效耗时恒等式不作为独立概率验证 |
| E2 开销 | 含等待墙钟中位数比 1.00001257 < 1.05；CPU 比 0.93150，不解释为插桩加速或单次调用误差界 |
| V102 时延 | 新三次分别 7、20、14 帧超时；H=20 的 80 个不重叠窗口分别成功 75、73、75；最大历史 100.718、253.294、183.183 ms |
| V101 时延 | 新三次均无超时帧，各成功 80/80 窗口；不等于真实概率为 1 |
| 定位质量 | V102 插桩 ATE RMSE 0.165、0.143、0.249 m；V101 为 0.039、0.041、0.050 m；原实用性未达标不改判 |
| 概率诊断 | 旧 9 次固定运行加新 6 次插桩，共 15 次 / 24,000 帧复核；旧 V102 fixed-loop 第 1/2 次构造候选，其余分角色检查，配置/序列不混池 |

真实案例表明：旧批第 1387 轮 B 耗时 221.984 ms，而该轮输出 T 仅 13.068 ms，按时；下一轮历史为 185.052 ms，此后五帧超时，第 1393 轮历史仍正但恢复按时，第 1394 轮历史清零。此现象符合原模型，不能因后台长任务或正历史而判模型失效。

单模式候选在新 V102 三次检查中，加入历史后 T 对数均方误差下降 66.64%、81.09%、65.76%。上一轮关键帧模式下仍下降 66.22%、80.82%、65.13%。看到信号后的分解检查发现：仅预测执行时间、去掉积压变量仍有相近改善；因此不能归因于启动间隙或认为消除积压即可解决。因果来源尚未定位，B 的筛查未触发也不能作为独立性验收。

上一轮关键帧候选还使下一模式与本轮后端工作相关：当前模式为 0 时，按训练 B 耗时中位数分层，新三次低层的下一模式为 1 的比例均为 0，高层分别 33.33%、23.76%、21.03%。需要检查原第三项条件，不能将这种标签直接当作满足 F_m(dS)Q_mm' 的模式。数学模式可为潜在变量；在线是否可观测另列，不能混同概率条件。

当前可以继续 E4 的模式构造与核验，不能宣称已得到真实可靠度的认证预测。下一项从场景/地图/工作量/资源的机制及信息产生时点入手，提出少量跨运行可复用的候选，分别核验模式内耗时历史依赖、Q 的历史依赖、当前耗时与下一模式的条件关系。冻结候选及容许误差后采集新的完整运行验证；现有已看过数据仅作开发/诊断。不得通过给每帧分配独立模式记住序列，或用自回归核偷偷替换原模型。保留原生功能及实际应用能力要求，不因候选未通过默认删减复杂功能。

三个新运行重复的是同一图像轨迹，并非独立场景；非重叠窗口也可能相关且初态不同，其比例不直接等于固定初态的 R_H。无独立二项置信区间、无由不显著推出独立的验收。短重复和少量长事件仍不足以认证尾部分布或一般自动驾驶适用性。
