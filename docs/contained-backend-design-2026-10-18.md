# 模块内部并行与同步回环：实施前设计

2026-10-18。续接 [E3 长段失败记录](effective-duration-continuation-2026-10-18.md)，本轮单独保存构建和数据，不覆盖原二进制、失败或既有 E2 基线。

## 模型及软件边界

外部图仍为 `B(k-1) → T(k) → B(k)`，输出仍是 T 返回时的在线相机位姿。T 内允许原有左右特征提取并行，两个线程均 join 后才继续；B 顺序完成本轮 LocalMapping、回环检测、校正及原算法触发的 GBA。GBA 在调用线程完成，不能留后台写图；不移动到下一轮、不丢弃工作、不强制关键帧。合图沿原非惯性分支执行并在 B 内返回。固定模式仍仅接受 pinhole 非惯性双目、无 Viewer/Atlas 文件；其他模式保持原生入口。

新增显式选项 `Execution.synchronousLoop: 1` 配合 `loopClosing: 1`；未显式授权的固定回环设置仍拒绝。`Execution.serialStereo` 缺省保持旧行为（固定串行、原生并行），显式 0 才让固定 T 并行。不会更改进程级 OpenCV/Eigen 线程策略。

同步回环只能在 mapper 的 ProcessRound 返回且队列为空后调用；同步停止直接确认 mapper 空闲，而不等待不存在的建图线程。原生停止路径不变。同步 B 返回前检查回环队列为空、无 GBA 线程、无运行中的 GBA、mapper 未停止。异常使固定 API 进入 Fault。重置清理回环候选引用；关闭只能在任务边界结束。

观测每轮 T/B 返回后的线程数量与回环/校正/合图/GBA 累计计数。内部两个特征线程的峰值最多允许 3（调用线程+两个提取线程）；每个外部边界必须回到单线程。不能通过删除原单线程检查来接受后台工作；旧审计默认契约保留，新契约显式声明 joined_stereo。边界采样和源码审查共同支持范围判断，并非通用线程无竞态证明。

有效耗时仍为就绪后间隙加模块墙钟耗时，阻塞式 GBA 全部进入 B。旧三项概率条件不变；记账恒等式仍非预测验证。在线位姿不以事后校正轨迹替代。

## 依次验收

1. 新独立构建（现有依赖只读复用）；记录源码、二进制、实际链接库与工具哈希。旧构建保持不变。
2. 固定串行/并行/同步回环的 API 顺序、错误配置、重置、关闭自测；检查原生入口仍可运行。审计器对越界线程、后台 GBA、跨轮队列给出拒绝结果。
3. V102 从序列起点连续 1600 评估帧，质量预定 k=20..1599，所有帧参与其他门槛；固定串行无回环、固定并行无回环、固定并行同步回环、原生默认四配置，各 3 个新进程。顺序循环错开，串行计时。该批为诊断重复，不是留出集或新 E2 通过。
4. 数值门槛保持 h=τ=50ms、H=20、ATE≤0.15m、有效位姿/GT覆盖≥99%、固定重置0、按时≥99%、吞吐≥19Hz、CPU≤1等效核、RSS≤2GiB；相对质量≤1.25×配对原生+.02m、CPU≤1.2×原生+.02核。回环长任务不可放宽截止或删除积压帧。
5. 如有质量/时限失败，保留各次结果及回环发生帧，继续完成预定诊断重复以判断稳定性；不得进入正式 E3 加载采集/E4。只有兼容性、测量及可用性合格，才安排新版本 E2 与原定跨序列/共享资源 E3。冷启动限制仍保留。

源码覆盖不等于实测分支覆盖：未发生合图/GBA/复位后的重定位时逐项记为未覆盖。没有运行的测试不得写成通过。
