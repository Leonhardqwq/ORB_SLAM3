# 主动控制工作量以检验模式条件

2026-10-19，用户授权从直接影响耗时的角度改造并实验。承接 Tracking 阶段诊断；保持原概率条件、固定图及完整后端。目标是使有限模式足以描述新产生的 T/B 联合耗时，不是消除历史积压。有限实验只能支持声明范围内的近似适用，不能将反复调参直到不显著当成独立性证明。

## 实施与验收顺序

1. **可选真实计算干预。** 在固定非惯性双目 T 内增加局部工作集合选择：按当前匹配投票排序，票数相同按关键帧 ID；邻接关键帧按既有相关结构补充；从不同视角交错选取地图点。完整地图不删除，当前已有匹配、重定位、初始化、关键帧生成、LocalMapping、同步回环和完整 GBA 保留。原生入口默认关闭。验收：关闭路径保留；错误线程/阶段/参数被拒绝；异常恢复；局部选择实际不超过预算。
2. **两档预算成为主动设置。** 低档 16 个关键帧/1200 点，高档 32/2400；通过 API 可配置。只有参与局部投影搜索的工作集合受限。投票、复制、去重、全部后端及其他 T 工作仍计时；不声称全部操作数或墙钟耗时有界。选择不足时不填充、不补睡眠；不丢图像或超时任务。
3. **固定三组并独立构建。** 原路径（control=0）、稳定选择但无限额（1）、稳定选择加两档预算（2）；全部使用同一新库和阶段记录。两条既有 EuRoC 视频，每组 3 个完整进程重复，1600 帧，块内随机顺序，串行。旧数据只读。低/高模式的转移概率设为 1/16，独立于图像、SLAM 结果和时延预生成；使用独立 xorshift32 流记录种子和实际模式。理想独立随机源下此控制链的转移机制是外生的；有限确定种子的伪随机回放不等于数学独立性证明。
4. **固定开发筛查。** 每序列/每组 block 1 拟合，block 2/3 检查。控制模式、旧输入四模式及其组合分别报告；历史增益同时检查 T、B 和同轮乘积/长耗时代理，比较时间趋势及输入解释量。主要筛查要求是各检查运行的额外历史 log-MSE 相对改善不超过 10%；这是本轮事前工程筛查线，不把未超线自动升级为 E4 正式通过。报告实际预算触发比例、T/B 分位数、ATE、无效位姿、CPU/RSS、窗口观测。V102 ATE 仍用 0.15 m；不提高门槛。
5. **按机制迭代。** 若预算实际未触发，不能称此干预有效；若触发且定位保持，可分析直接减少的搜索量和剩余来源。若定位恶化，不继续一味压小预算。若历史主要残留于未受控 B/图像处理，优先明确其机制及分布接口，不能通过增加逐帧模式或扩大方差掩盖。已有视频只作开发，所有结果保留，当前不足不阻止进一步诊断。
6. **独立验收再进入 E5/E6。** 候选、作用范围、统计等价容差和样本量确定后，使用新场景的独立检验，分别核验联合律历史条件、模式 Markov 条件及服务/下一模式关系，评估尾部和预测。不能以控制链外生性替代第一项条件，也不能以本轮诊断直接宣布可靠度认证。定位及资源应用验收独立保留。

本轮是开发干预，不宣称已经为最终验收算出样本量；未接触的新场景保留。源码/命令/结果另行归档，不提交缓存或原始批量逐帧输出。没有 Git 暂存、提交或推送授权。

设计使用 experimental-design 技能的整进程重复、分块随机、同库对照与开发/验证分离建议。按技能说明记录工具来源：Kassis et al. (2026), *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*, arXiv:2609.00065，https://doi.org/10.48550/arXiv.2609.00065；本轮未联网核验题录，不作科学事实证据。
